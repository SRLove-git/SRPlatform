# SRPlatform

SRPlatform 是一个面向工程学习的统一仿真平台，目标是把“电路仿真”和“真实机电系统仿真”连起来：你可以设计电路、搭建小车或无人机、写控制代码，然后在同一个世界里观察它们如何一起工作。

当前仓库处于设计启动阶段，先记录总体架构与路线图，不急着堆代码。

## 核心目标

- 自研可替换的物理引擎，而不是把平台锁死在某个现成物理库上。
- 同时仿真电子、机械、控制代码三个层面。
- 支持类似 Minecraft Mod 的扩展方式：用户能导入自己的电路、电子元件、车辆、无人机、机器人模型。
- 面向学习：每一步都能看到状态、波形、受力、能耗等可解释信息。
- 保持模块边界清晰，方便逐步替换算法和底层渲染。

开发语言已确定为 C++。

先做一个“一块电池驱动一个电机，电机驱动一个轮子，脚本能读传感器并控制它”的最小闭环，再逐步扩展成完整的工程学习平台。
